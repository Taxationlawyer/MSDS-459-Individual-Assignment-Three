## Part Five, Sentiment Analysis Investing

Sentiment Analysis of investing consists of using information scraped from the World Wide Web, especially social media (e.g., X—formerly known as Twitter), to assess the value of a company’s stock. Comments about the company are classified (using machine learning and other methods, the BERT model can be used) as positive (favorable) or negative (disparaging) towards the company. 

The benefits of using sentiment analysis for investing are that information is readily available and the BERT model (transformers—artificial intelligence) can be used to classify the comments about the company. Moreover, it has been shown that there is some association between the company stock and the public sentiment about the same stock. 

The limitations of using sentiment analysis include the fact that it is only a small part of the whole decision-making process. Additionally, sentiment analysis does not directly account for factors like historical (market price) and fundamental analysis information.

In sum, sentiment analysis investing can be used as a part of the whole decision-making process that includes technical and fundamental analyses information to make well-reasoned and evidence-based decisions.
